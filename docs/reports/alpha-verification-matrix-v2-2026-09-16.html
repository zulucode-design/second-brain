Gate boundary

External-alpha product support is exactly Windows 11 x86-64 and Fedora 44 Workstation x86-64, as settled by ADR-0012 and issue #88. The Windows package for this gate is NSIS; the Fedora package is RPM. Existing Ubuntu, deb, and Windows Server jobs remain useful build infrastructure, but they do not establish product support. MSI, AppImage, macOS, Android, iOS, Ubuntu, and newer Fedora releases are outside this gate.

The tested capacity baseline is 10,000 notes in one logical vault. It is not an enforced maximum. All manual tests use disposable vaults. No verification step may mutate the production vault.

Candidate invalidation rule: final performance and package evidence names one commit. A later change to runtime code, dependencies, packaging, capabilities, or configuration invalidates the affected evidence and requires that row to be rerun.

Final package walkthrough

Run once on each supported machine against packages built from the same candidate commit. Record OS version, package filename and SHA-256, commit, start/end time, screenshots, and relevant diagnostic export.

  1. Install the package and launch it from the installed desktop/start-menu entry.
  2. Open a clean disposable vault; confirm all four PARA roots and no repair issues.
  3. Capture a note, edit it, navigate away immediately, reopen it, edit it again, and close the app immediately. Confirm both saves survived.
  4. Exercise keyword search, semantic search, graph, tasks, trash restore, note history, backup, and transactional restore.
  5. Clip a reachable web page and attach a local file. Confirm AI-offline mode leaves capture, editing, organization, and keyword search usable.
  6. Publish one disposable note to Notion when credentials are available; otherwise record the external-service block without using a production note.
  7. Display the malformed-config startup error from package F, then restore the disposable configuration.
  8. On Windows, perform #49's renamed-vault hotkey check and confirm the installed notification appears.
  9. Export diagnostics and run the planted secret/body/path assertions against the produced archive.
  10. Exit normally; confirm no app, sidecar, or watchdog process remains. Uninstall; confirm the disposable vault remains.
