Issue 238: gray_matter 0.3 verification

2026-10-26. The branch upgrades gray_matter from 0.2.9 to 0.3.2 and routes front matter reads through one helper that preserves the body when YAML cannot be read. Following the approved attempt-2 decision on #238, each metadata field reads independently: a wrongly typed field no longer hides the category or other readable fields. Import shares the id, title and list-tag readings, while retaining its Obsidian tag conversion. Trash restore accepts a changed id reading when the recorded content hash proves the file is unchanged.

Publication is pending. Installed-package checks passed on Fedora and Windows. Windows full verification retains the #244 test failure; changed-id history/Notion continuity remains unfixed under #248. The report commit and whole branch still need final review on both axes before any push or PR, then CI and separate merge approval.
