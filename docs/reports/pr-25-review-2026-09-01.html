New regression safeguards · 2 September

SafeguardWhat it prevents
Validated ApplicationIdRejects empty, spaced, underscore, non-reverse-DNS, and empty-segment identifiers before portal use.
Canonical configured identifierPortal and desktop-entry APIs cannot silently use an unrelated string literal.
Source consistency testChecks Debian/RPM destination names and shared desktop fields against the configured id.
AppImage writer and startup-gate testsProves first write, no-op for a current entry, refresh after a move, and refusal to register when required integration cannot be prepared.
Activation lifecycle testProves a capture-window failure becomes an unavailable status that tells the listener to end the portal session.
Status ordering testProves Available is published before the activation listener becomes runnable, preventing a truthful failure from being overwritten.
Finished-package CI checkBuilds an unsigned Debian package, extracts it, and byte-compares the installed app-id entry with the reviewed source entry.
