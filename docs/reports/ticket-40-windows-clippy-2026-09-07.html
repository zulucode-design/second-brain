Ticket #40 — Windows strict-Clippy remediation

Updated 2026-09-07. This report records the narrow source fix for the Windows-only dead_code warnings found after ticket #27.

Finding

The Unix-only crash-recovery test kills a child process with Unix process semantics. Its test-only helpers were nevertheless compiled on Windows, where no test referenced them. With warnings denied, Windows Clippy therefore failed before it could provide a clean quality gate.

Remediation

The helpers now have the same availability as the test that uses them:

  • machine_local::TEST_ROOT_VAR, test_root(), and the test-only environment override compile only for Unix tests.
  • The crash-test constants and body helper compile only for Unix tests.

No production behavior, Windows runtime path, or test result is changed. On Windows the unavailable crash-kill test remains deliberately absent; its required recovery verification is manual, as recorded for ticket #27.
